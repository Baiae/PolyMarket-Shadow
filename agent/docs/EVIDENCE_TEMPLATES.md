# Market-Specific Evidence Templates

Poly-Shadow can expand a frozen evidence-manifest URL from market identity before a forecast is issued. This lets one preregistered evidence protocol retrieve relevant independent context for many markets without allowing the forecasting model to choose its own sources.

## Supported placeholders

Remote evidence `source` URLs may contain:

```text
{condition_id}
{gamma_market_id}
{slug}
{question}
{gdelt_query}
```

Every replacement is URL encoded. Unknown placeholders fail closed. Inline `content` entries remain static and cannot use source templates.

Example:

```json
{
  "markets": {
    "*": [
      {
        "source": "https://api.gdeltproject.org/api/v2/doc/doc?query={gdelt_query}&mode=artlist&maxrecords=25&timespan=30d&format=json",
        "title": "GDELT recent news search"
      }
    ]
  }
}
```

The raw manifest is what a qualification cohort hashes and preregisters. During collection the same frozen template is rendered independently for each market, then returned JSON or text is hashed and stored in the forecast journal before provider invocation.

## Deterministic query construction

`{gdelt_query}` is generated by code from the Polymarket question; it is never generated by an LLM.

The transformation removes a leading question word, removes common stop words, preserves useful names/numbers/date terms, prefers the first multi-word capitalized phrase as an exact-phrase anchor, otherwise uses the first content token as the anchor, and adds up to four additional unique terms in one GDELT `OR` block.

Example:

```text
Will bitcoin exceed 100,000 dollars before September 2026?
→ bitcoin (exceed OR 100000 OR dollars OR September)
```

This is a stable retrieval rule rather than an optimized search strategy. Changing it requires normal code review. For a running fixed qualification cohort, the evidence manifest, provider configuration, forecast protocol, and qualification policy are separately frozen by hash.

## Recommended first-cohort source

Use the GDELT DOC 2.0 Article List API with:

```text
mode=artlist
format=json
maxrecords=25
timespan=30d
```

This produces bounded recent-news evidence rather than a generic wildcard page. The model receives the frozen returned evidence, not the market baseline unless a separate experiment explicitly enables baseline visibility.

## Failure behavior

Evidence collection still occurs before forecast issuance. A transport error, unsupported content type, empty response, malformed source template, or unsearchable market question fails that market collection attempt rather than silently falling back to market metadata in qualification mode.

An HTTP 200 JSON response containing no matching articles is valid evidence of the deterministic search result; the forecaster may abstain when evidence is insufficient. Abstentions reduce cohort coverage and therefore cannot improve qualification by hiding hard markets.
